# /build-site — Starter prompt pour lancer un site $10K

Build a modern landing page for [DESCRIBE YOUR BUSINESS/CLIENT HERE].

Requirements:
- Use Next.js with the App Router
- Tailwind CSS for styling
- Framer Motion for all animations (scroll-triggered fades, staggered reveals, hover transitions)
- Include sections: sticky navbar, hero with CTA, features/services, social proof/testimonials, pricing (if applicable), footer
- Follow the design tokens defined in the frontend-design skill (typography scale, 8px spacing grid, color tokens)
- Mobile-first, fully responsive (375px / 768px / 1280px)
- Target Lighthouse score 90+ on performance

Start by setting up the project structure, then build section by section. Use the frontend-design skill for all design decisions.
